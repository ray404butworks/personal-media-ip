## 实际回归

- 28项Python测试通过，含向导续接、标题限制、外部音轨对齐与打包路径边界。
- Node离线检查通过：完整/截断/失败响应、原文、实测时间范围、男女/混合声池、整期锁声、三音色专属语速、缓存失效及两种制作入口。网络被禁止，无新增付费合成。
- 长字幕按对应实测词边界切分，快慢不同的词段不再平均分配整句时长；错稿拒绝。调查字幕空白段落与原生时间边界用隔离样本验证。
- Remotion4.0.544实际渲染6秒1080p/30fps模板；白板实际渲染8.5秒带音轨/字幕/片尾模板。两者全片解码通过，实际截图查看品牌及中文字形。
- 完整交付器用已经完成的3分23秒成片及双封面、四平台/公众号原文件回归，真实生成实体交付和CRC有效ZIP；私人素材仅在被忽略的workspace，不进入公开仓库。
- `.env`、本机状态、node_modules、工作区、音频/成片、私有ID和缓存排除；源码包检查CRC和逐文件SHA256。G盘本机真实凭据值在上传前比对，值不输出。

## 复现

```text
python -m pip install -r requirements.txt -r requirements-audit.txt
npm ci --ignore-scripts
python scripts/apply_config.py
python -m unittest discover -s tests -p test_*.py
npm run test:narration
npm run check:comments
python scripts/release_audit.py
npm audit
npm audit --package-lock-only --prefix skills/whiteboard-video
npm audit --package-lock-only --prefix skills/investigation-video/template/remotion
python -m pip_audit -r requirements.txt
python -m bandit -r scripts skills/whiteboard-video/lib skills/investigation-video/scripts
```

FFmpeg、FFprobe、Node须可从PATH定位；Windows建议设置PYTHONUTF8=1。根npm只装审计用解析器；视频运行依赖按对应技能目录npm ci安装。检查后使用scripts/package_release.py生成新版源码包，已有包不覆盖。
