# 每期完整交付

默认生成完整交付，局部修改按当次范围。已确认的稿件、音色、品牌、音乐和制作方向继续沿用。

```text
workspace/<当期>/
  受众审查.json
  旁白选择.json
  knowledge/             口播、来源、画面注记、审校与发布正文
  work/                  素材、真实音频/时间戳、工程与检查记录
  delivery-manifest.json 文件映射，路径相对当期工程
  outputs/<题名>-完整交付v1/
    <题名>-完整v1.mp4
    <题名>-字幕v1.srt
    发布包/              双封面、四平台MD与各平台TXT、公众号MD/TXT
    来源与检查/          来源、素材区间、审校、音画检查与受众选声记录
    先读我.md
    交付清单.json
  outputs/<题名>-发布素材v1.zip  不重复包含MP4
```

Agent创建映射后运行 `python scripts/finalize_outputs.py <当期工程> --title <题名>`。格式见 `workflow/delivery-manifest.example.json`；示例占位路径不能当真实验收结果。

脚本检查完整视频解码、音轨、字幕时间与文本、封面比例、四平台限制、公众号MD/TXT一致、已记录音画QA、工程内路径及密钥文件排除，再生成实体交付、SHA256清单与CRC通过的ZIP。失败不标成已交付。

机器检查不能证明来源真实、素材版权、审校质量或完整听感。Agent须实际阅读、查看关键帧，并记录已完成与未完成的检查；人类复核状态独立记录，不由脚本代签。
